# Run a CommonFunded fit assessment

Use the [quote output guide](../AI-instructions.md#quote-output-guide) to present the result. Start with the [runnable account example](example-analysis.json). To change an input and run the comparison again, use the [public commands](README.md#run-a-comparison) or the [REST/MCP guide](explorer-context.md).

For a group-specific analysis, match quoted rates, benefits and enrollment to the same period. State whether the upper-layer price is fixed or includes estimated retained claims. When using de-identified history, check coverage periods, zero-claim members, incurred versus paid dates and any change in networks or prices. Reconcile the current plan to known payments before claiming historical accuracy.

If an assumption could change which design wins, rerun that assumption at the offered rates and report its effect on monthly savings. If the result already answers the user’s question, give them the decision.
