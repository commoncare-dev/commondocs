# Explore CommonFunded

CommonFunded separates account-funded routine care from the financing of larger medical claims. This explorer tests whether the cost released by changing the coverage arrangement exceeds the cost of funding the additional participant cost sharing through an account. It also reports changes in participant costs so that moving an expense between people is not mistaken for a saving. The choice of insurance, self-funding or stop-loss for the larger-claim layer is a separate decision.

For a general exploration, use the explorer's `exampleResult` to explain the numbers calculated from its hypothetical account example; it is returned in the initial response and does not require your environment to make a POST request. If the example is unavailable, say so and do not invent its results. For a user-specific analysis, adapt inputs and call available tools yourself; ask the user only for information needed. If you cannot make a required request, say so and offer a ready-to-run request or the public script. Label hypothetical inputs and individual-market benchmarks clearly.

The [public CommonDocs directory](https://github.com/commoncare-dev/commondocs/tree/main/plan-structures/common-funded) contains the concept and [analysis scripts](https://github.com/commoncare-dev/commondocs/tree/main/plan-structures/common-funded/analysis). An agent with repository and shell access can clone it and run `node run-analysis.mjs example-analysis.json` from the analysis directory without CommonCare. The example uses hypothetical inputs. The standalone generator and CommonCare GPS generator have different spending assumptions; see the analysis guide before comparing results.

Alternatively, connect an agent to CommonCare MCP at https://mcp.commoncare.org/mcp to call the tools directly using the connected account's permissions, or use the REST actions in this response. CommonCare's benchmark prices are individual-market references, not group quotes; the analysis accepts supplied prices and assumptions. For an explicitly requested full quote, MCP can create or prepare a saved GPS record, add census, and run the GPS simulation; `get_full_quote` lists the steps.
